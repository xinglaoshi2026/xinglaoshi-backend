做题步骤说明

  1. 第1步：点最上面 打印题目，把题目打印出来（也可以直接看屏幕），把今天所有题目的答案/计算过程写在同一张纸上。
  2. 第2步：翻到题目下面的「做完拍照上传」，点「拍照 / 选照片」选中照片——可一次选多张、也可分几次拍。选好后会先在本页预览，拍糊的可点 × 删掉重拍，此时还没上传。
  3. 第3步：确认照片没问题后，点「上传照片」，照片才真正上传；上传成功后每道题会自动显示答案与解析，无需再点「查看答案」。
  4. 第4步：对照答案给自己打分：做对了 / 半对 / 做错了。
  5. 第5步：如果自评是半对或做错了，请写下错误原因（必填）；自评做对了可不填。
  6. 所有题目都填完后，点最下方 提交今日练习。
  7. 做错的题过几天还会再出现；每天只练 3 道，花几分钟就好。
  8. 完成练习后可点 下载我的错题本 导出全部错题（含答案）。

在浏览器里下载

微信 / QQ 里不能直接下载 Word，已为你生成一条下载链接（30 分钟内有效），复制后到浏览器打开就会自动下载。
  1. 点上面的 复制链接
  2. 打开手机的浏览器（Safari / Chrome / 手机自带浏览器都行）
  3. 在地址栏长按 → 粘贴 → 前往，就会自动下载 Word 文件
另一个办法：点右上角 ⋯ → 在浏览器打开，回到本页再点一次。
链接过期了也不要紧，回到本页重新点一次，会给你一条新的。
不打印也可以直接看着屏幕上的题目做，做完拍照上传一样可以。
